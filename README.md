# My Blog

A personal blog built with [Hugo](https://gohugo.io/) using the PaperMod theme.

## Requirements

* [Hugo](https://gohugo.io/)
* Git

## Run locally

```bash
hugo server -D
```

Then open `http://localhost:1313` in your browser.

## Build

```bash
hugo
```

The generated website will be available in the `public/` directory.
